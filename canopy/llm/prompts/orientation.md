# DIRECTION OF THE MEASURE

For ONE measure in the attached paper, decide what a LARGER raw value means.

This is a question about the measure, not about the groups and not about the result: if the number
counts how far a response fell from where it should have been, a larger value means more error and
therefore *less* of the construct the review is about; if it counts how much of the response was
correct, a larger value means more of it.

Answer three things.

1. `raw_value_semantics` — what a larger raw number is more of:
   * `higher_more_construct` — more of the quantity the outcome definition describes;
   * `higher_more_error` — more deviation, more mistake, more cost, more time to do a task;
   * `signed_direction` — the sign carries a direction, so the magnitude alone means nothing;
   * `unknown` — the paper does not let you tell.
2. `higher_is_better` — `higher`, `lower`, or `unknown`, read together with the outcome definition
   below: does a larger raw value on this measure mean MORE of what this review is measuring?
   Answer `unknown` rather than guessing; a wrong answer here inverts every result built on it.
3. `direction_stated_in_text` — which group the paper itself says came out higher **on this raw
   measure**: `a_greater`, `b_greater`, or `unknown` when the paper does not say. This is about the
   paper's own words, not about which group is better off.

Put the verbatim words that establish your answer in `quotes` — the definition of the measure in
the Methods, the axis label or caption, the sentence that describes the result. Two or three short
quotes are better than one long one. If the paper never defines the measure, say so in `reason`
and answer `unknown`; do not fall back on what the measure is usually called elsewhere.
